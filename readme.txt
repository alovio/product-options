Add custom product fields with conditional logic — free. A modern drag-and-drop builder, live preview, and add-on pricing for WooCommerce.

== Description ==

Most product add-on plugins lock conditional logic behind a paid upgrade. **Advanced Product Options gives you conditional logic for free** — show, hide, or require fields based on what the customer chooses.

Build your fields with a modern drag-and-drop editor, preview them live, and let selections add to the price — all flowing correctly into the cart, checkout, and order.

**Free features**

* Field types: text, text area, number, checkbox, radio, dropdown, and fixed-fee surcharge
* **Conditional logic** (show / hide / require a field based on another field)
* Drag-and-drop builder with a live preview tab
* Fixed add-on pricing per field
* Required-field validation
* Cart, checkout, and order display of chosen options
* HPOS (High-Performance Order Storage) compatible
* Translation-ready

**Pro (coming soon)**

Advanced multi-condition logic, dynamic price formulas, file upload, date/time pickers, color & image swatches, multi-step forms, and global option groups.

== Installation ==

1. Upload the plugin to `/wp-content/plugins/` or install it from the Plugins screen.
2. Activate it. WooCommerce must be active.
3. Edit a product and use the **Product Options** panel to add fields.

== Frequently Asked Questions ==

= Is conditional logic really free? =
Yes. Showing, hiding, and requiring fields based on another field's value is in the free version.

= Is it compatible with HPOS? =
Yes — order data is written via WooCommerce CRUD APIs.

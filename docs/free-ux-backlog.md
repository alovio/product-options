# Free-tier UX / value backlog (5-agent audit, 2026-06-01)

54 free-scope findings ranked by value then effort (dimensions overlap).

- **[high/low]** (builder-ux) No field duplication
  - Add a 'Duplicate' op button (e.g. ⧉) next to the delete button in Canvas.jsx, plus a `duplicateField(id)` action in reducer.js that deep-clones the field, assigns a fresh id via makeId(), inserts it right after the source, and selects it. Deep-clone `options`/`condition` so the copy is independent.
- **[high/low]** (free-value) Options total has no currency symbol (renders bare "+0.00")
  - In FrontendAssets::enqueue(), wp_localize_script an `APO_FE` object with currency context from WooCommerce: { symbol: get_woocommerce_currency_symbol(), decimals: wc_get_price_decimals(), decimalSep: wc_get_price_decimal_separator(), thousandSep: wc_get_price_thousand_separator(), format: get_woocommerce_price_format() }. In price-update.js wirePrices(), format `total` using those settings instead of `toFixed(2)`. In ProductFormRenderer.php render the initial value formatted with the symbol (or wrap in a wc_price-style span) instead of the literal '+0.00'. Keep PHP authoritative; this is display-only so no security impact.
- **[high/low]** (a11y) No visible focus styles for frontend controls or swatch radios; swatch focus indicator is missing entirely
  - Add .apo-swatch input:focus-visible + .apo-swatch__dot { outline: 2px solid #4f46e5; outline-offset: 2px; } (mirroring the :checked rule) in both frontend.css and builder.css. Add a generic :focus-visible outline for .apo-field input/textarea/select so it survives theme resets. Ensure offset/contrast meets 3:1 against the page background.
- **[high/low]** (polish-i18n) Front-end validation error messages are hardcoded English (no __())

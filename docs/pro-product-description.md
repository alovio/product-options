## Overview

**CoreLabs Product Options Pro** is the premium add-on for the free [CoreLabs Product Options for WooCommerce](https://wordpress.org/plugins/corelabs-product-options/) plugin. It turns simple product fields into a powerful, rule-driven product configurator — so you can sell personalized, made-to-order, and configurable products and charge for every option accurately.

Build everything visually with the same drag-and-drop builder and live preview you already know. No code, no shortcodes, no bloat.

## What you unlock with Pro

### 🔀 Advanced conditional logic
Go beyond a single rule. Show, hide, or require any field based on **multiple conditions** combined with **AND/OR** logic, using five operators: *is, is not, contains, greater than, less than*. Build product forms that react intelligently to every customer choice.
*(The free version supports a single “is / is not” condition.)*

### 🎨 Colour swatch fields
Replace plain dropdowns with clickable **colour swatches**. Let customers pick a colour, material, or finish visually — cleaner, faster, and far more conversion-friendly on the product page.

### 📅 Date picker fields
Add a real **date field** with optional earliest/latest bounds — perfect for delivery dates, booking dates, event dates, or made-to-order lead times.

### 🔢 Per-unit pricing
Charge **per quantity** instead of a flat fee — e.g. *$2 per engraved character* or *$5 per extra item*. The price scales automatically with the number entered.

### 📈 Percentage pricing
Add an option fee as a **percentage of the product price** — ideal for gift wrapping, express handling, insurance, or premium finishing that should scale with order value.

## How it works

1. Install the free **CoreLabs Product Options for WooCommerce** from WordPress.org.
2. Install & activate **CoreLabs Product Options Pro** (this add-on).
3. Edit any product → the **Product Options** panel now shows all Pro fields, operators, and pricing modes.

## Requirements

WooCommerce · WordPress 6.4+ · PHP 7.4+ · the free CoreLabs Product Options plugin active.

## FAQ

**Do I need the free plugin too?**
Yes — Pro is an add-on that unlocks advanced features inside the free CoreLabs Product Options plugin.

**Will it work with my theme?**
Yes. It hooks into WooCommerce’s standard product form, so it works with any properly built WooCommerce theme.

**Is it compatible with HPOS?**
Yes, fully.

**Can customers see the price update live?**
Yes — the product page shows a running, currency-formatted options total that updates instantly, including per-unit and percentage fees.
